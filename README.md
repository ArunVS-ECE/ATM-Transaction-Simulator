# ATM Transaction Simulator

## About the Project
A simple ATM Transaction Simulator developed using C programming. It allows users to perform basic banking operations through a menu-driven interface.

## Features
- PIN verification with three attempts
- Check account balance
- Deposit money
- Withdraw money
- Track successful transactions
- Exit option

## Technologies Used
- C Programming
- VScode

## Concepts Used
- Variables and data types
- While and do-while loops
- If-else conditions
- Switch-case statements
- Arithmetic operators

## How to Run

Compile:
```bash
gcc atm.c -o atm
```

Execute:
```bash
./atm
```

## Project Level
Beginner-to-Intermediate level project.
